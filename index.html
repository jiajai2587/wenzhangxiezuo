使用说明

1. 内容管理

  1. 在"文章标题"输入框中输入引人入胜的标题
  2. 在"文章内容"文本框中输入或粘贴文章内容
  3. 点击"AI生成内容"按钮，使用AI自动生成文章内容
  4. 点击"生成图片"按钮，为文章生成相关配图
  5. 在"发布设置"区域选择要发布的平台
  6. 点击"一键发布"按钮，将文章发布到所选平台

2. AI检测

  1. 在"检测内容"文本框中输入需要检测的内容
  2. 点击"全段检测"按钮，对整个内容进行整体AI检测
  3. 点击"从内容管理复制"按钮，快速复制内容管理中的内容
  4. 查看检测结果，包括AI生成比例和同质化检测

3. 综合分析

  1. 点击"开始综合检测"按钮，对文章进行全面深度分析
  2. 查看内容逻辑与连贯性检测结果，了解文章结构
  3. 查看敏感和违规检测结果，确保内容安全合规
  4. 使用"一键优化清单"对文章进行优化

4. 工具集

  1. AI润色：输入需要润色的内容，选择润色风格，点击"开始润色"
  2. API接口设置：输入API密钥和地址，保存设置后可对接自定义AI服务
