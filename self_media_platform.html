使用说明

1. 内容管理

  1. 在"标题"输入框中输入文章标题
  2. 在"内容"文本框中输入文章内容
  3. 点击"AI生成内容"按钮，使用AI生成文章内容
  4. 点击"生成图片"按钮，为文章生成相关图片
  5. 点击"排版优化"按钮，自动优化文章排版
  6. 在右侧设置区选择要发布的平台、分类和标签
  7. 选择合适的AI模型（明亮、暗黑或流量推荐）
  8. 点击"发布"按钮，将文章发布到所选平台

2. AI检测

  1. 在"检测内容"文本框中输入需要检测的内容
  2. 点击"全段检测"按钮，对整个内容进行AI检测
  3. 点击"分段检测"按钮，对内容进行分段AI检测
  4. 点击"从内容管理复制"按钮，复制内容管理中的内容到检测框
  5. 查看检测结果，包括AI比例、分段检测结果和同质化检测

3. 流量预测

  1. 在"文章标题"输入框中输入文章标题
  2. 选择要发布的平台（微信公众号、微博或今日头条）
  3. 点击"预测流量"按钮，获取流量预测结果
  4. 查看预计阅读量、点赞数和评论数
  5. 查看流量趋势预测和优化建议

4. 综合分析

  1. 点击"开始综合检测"按钮，对文章进行全面检测
  2. 查看内容逻辑与连贯性检测结果
  3. 查看敏感和违规检测结果
  4. 查看营销文与广告浓度检测结果
  5. 使用"一键优化清单"对文章进行优化
  6. 点击"应用全部优化"按钮，自动应用所有优化建议

5. 工具集

  1. AI润色：输入需要润色的内容，选择润色风格，点击"开始润色"按钮
  2. 热门文章采集：输入关键词，选择平台，点击"开始采集"按钮
  3. API接口设置：输入API密钥和地址，保存设置后可对接自定义AI服务

6. 其他功能

  • 点击顶部导航栏的月亮图标切换暗黑模式
  • 点击"保存项目"按钮保存当前编辑的内容
